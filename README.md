# Maroon_LexicalAnalyzer
For Partial Completion of Principles of Programming Languages
BSCS 3-1 | Group 1

How to replicate:
1. Click the Green Code Button, and copy the repository link from there
2. Open your local terminal
3. Change the working directory to where you would like the repo to live
4. Type git clone with the previously copied link

How to run from the terminal:
1. Traverse to your chosen working directory
2. The repo has 2 current working files; compile both with
   
   gcc mainfile.c lexer.c -o mainfile.exe
   
3. mainfile.exe should now exist; type
  
   .\mainfile.exe
